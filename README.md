# Alimotion — maqueta funcional del sitio web

Sitio estático independiente en español, construido para la propuesta de Alimotion, sin referencias de marca a Metravib. Incluye portada, siete especialidades y contacto (9 páginas HTML), CSS compartido, JavaScript y favicon.

## Abrir

Abrir `index.html` directamente en un navegador moderno. Para pruebas de enlaces locales también puede ejecutar `python -m http.server 8080` en esta carpeta y visitar `http://localhost:8080`.

## Archivos

- `index.html`: inicio, posicionamiento, siete especialidades, metodología, sectores y entregables.
- `simulation-vibratoire.html`, `simulation-acoustique.html`, `fatigue-vibratoire.html`, `simulation-sismique.html`, `correlation-calcul-essai.html`, `qualification-virtuelle.html`, `simulation-oil-gas.html`: páginas de especialidad.
- `contacto.html`: formulario de demostración que genera un archivo de texto **sin enviar datos**.
- `assets/style.css`, `assets/app.js`, `assets/favicon.svg`.

## Pendientes antes de publicar

1. Confirmar idioma(s), país o países de comercialización, denominación legal, domicilio y aviso de privacidad.
2. Definir dominio, correo corporativo, teléfonos y canal seguro de envío para el formulario; conectarlo a un backend con protección contra spam.
3. Aprobar las capacidades y el software efectivamente licenciados para Alimotion. No se deben presuponer contratos, certificaciones, laboratorios propios o colaboración institucional.
4. Validar referencias técnicas, normas aplicables a cada proyecto y cualquier cifra, promesa o testimonio que vaya a publicarse.
5. Incorporar fotografías y visualizaciones propias, con permiso explícito, y configurar analítica/cookies según la regulación aplicable.
6. Sustituir enlaces de Google Fonts por fuentes alojadas localmente si se requiere funcionamiento completamente sin conexión.

## Nota técnica y ética

El contenido de la maqueta HTML suministrada por el usuario se utilizó para identificar las siete especialidades y sus temas técnicos. La redacción y el diseño de Alimotion son nuevos. Los casos expuestos son hipotéticos y se identifican como tales. La simulación apoya la justificación técnica pero **no implica certificación automática ni garantía de ausencia de fallos**. No se publican referencias de clientes actuales del empleador del promotor.
